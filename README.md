# OpenPallet schema

The JSON Schema of the OpenPallet file, the open exchange format for palletizing data, and later its validator.

**Status: OpenPallet 1.2.**

## Contents

- [`openpallet-1.2.schema.json`](openpallet-1.2.schema.json): JSON Schema (draft 2020-12) of the OpenPallet 1.2 file
  (`format: {"name": "OpenPallet", "version": "1.2"}`).
- [`examples/1.2/`](examples/1.2/): three pallets as OpenPallet 1.2 files, each valid against
  `openpallet-1.2.schema.json`: a pallet without a mix (`Water EUR2 5 layers`), a mix of three product types
  (`Juices mix 3 flavours 6 layers`), slip sheets on the pallet and on every second layer (`Juices Apple 6 layers
  slip sheets`).

The schema is generated by PalletDesigner from the code that writes the files, the examples are written by
PalletDesigner.

Specification and cards: [openpallet/spec](https://github.com/openpallet/spec) · <https://openpallet.org>
